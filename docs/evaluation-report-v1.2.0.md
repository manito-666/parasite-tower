## 八、结论与建议

### 上线判定：**可以上线**（与 v1.0.0 同级，质量更高）

v1.2.0 在内容深度、代码组织、新手体验、国际化方面都有显著提升。仍存在的两个关键空白：**云端排行榜后端未启动** 和 **DLC 支付未接入**，前者是体验缺口，后者是商业缺口。

### 上线前必做（1–2 天）

1. **同步 versionName 1.1.0 → 1.2.0**（gradle 与 CHANGELOG 对齐）
2. **隐私政策页面托管**：当前 `ui/panels.js` 已有文案，需放到公网 URL，应用商店表单填写
3. **商店截图**：6–8 张（战斗/附身/地图/污染/职业选择/短局结算/海报/中英切换）
4. **小范围内测**：3–5 人覆盖全流程（特别是 DLC 解锁、中英切换、锚点回滚）

### v1.3 必做（上线后 1–2 周）

1. **启动排行榜独立项目**（已有完整计划文档）
2. **机甲/血族 effect 键补完**（6 个键的 combat.js 消费）
3. **DLC 支付接入**（Google Play Billing）
4. **删除冻结代码**：`internal/` 镜像 + 未使用的 `pixi.min.js`

### v2 规划（3–6 个月）

1. HMAC 签名反作弊
2. "删除我的服务器数据" 接口（GDPR/PIPL 合规）
3. 周榜结算 + 冠军徽章
4. 形态亲密度 4 级低语叙事（首发收缩项放出）
5. 30 个完整楼层签名 + 15 对完整诅咒祝福
6. 接入 Crashlytics 收集 WebView 崩溃
